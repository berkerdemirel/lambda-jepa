## 1 · Paper 1 — Dubois et al. '21, arXiv 2106.10800

### Claim 1(a): formalizes "minimize rate s.t. lossless prediction of every task invariant under the view/augmentation group" — **VERIFIED** (one precision: equivalence relation, not group)

Abstract: *"In this paper, we characterize the bit-rate required to ensure high performance on
all predictive tasks that are invariant under a set of transformations, such as data
augmentations."*

The distortion (§3.1, Eq. 2) is worst-case excess risk over the task set — ⟨math transcribed⟩:

> D_T[X,Z] := sup_{Y∈T} R[Y|Z] − R[Y|X]   (Eq. 2)
>
> *"If D_T[X,Z] = 0, it is possible to achieve lossless prediction: performing as well using Z
> as using X."* (§3.1)

Invariant task set (§3.2, Definition 1): *"The set of invariant tasks of interest with respect
to an equivalence (X,∼), denoted T∼, is all random variables Y such that x ∼ x⁺ ⟹
p(Y|x) = p(Y|x⁺) for any x, x⁺ ∈ X."*

The objective/theorem (§3.3, **Theorem 2, Rate-Invariance**), verbatim (math transcribed):

> *"Assume the conditions of Prop. 1. Let δ ≥ 0, and Rate(δ) denote the minimum achievable
> bit-rate for transmitting Z such that for any Y ∈ T∼ we have R[Y|Z] − R[Y|X] ≤ δ. Then
> Rate(δ) = 0 if δ ≥ H[M(X)] and otherwise it is finite and*
> Rate(δ) = H[M(X)] − δ = H[X] − H[X|M(X)] − δ.  (Eq. 5)"

Lossless case: *"To ensure lossless prediction, i.e., Rate(0), our theorem states that we
require a bit-rate of H[M(X)]."* Footnote 4: *"We prove in Sec. B.5 that Rate(0) = H[M(X)] for
any losses used in ML."* Prop. 1 (§3.3, Eq. 4) reduces the distortion to D_{T∼}[X,Z] =
R[M(X)|Z] under: M countably-valued, H[M(X)] < ∞, log loss.

**Precision required:** invariance is w.r.t. a user-declared **equivalence relation ∼**, which
the paper is explicit generalizes group actions — footnote 3: *"This extends the definition of
maximal invariants [19] beyond invariances to group actions."* For augmentations, App. C treats
the augmented A(X) as source and *"the unaugmented X as the maximal invariant task M(A(X))"*.
So "view/augmentation group" in our table should read "augmentation-induced equivalence
(⊇ group orbits)". The constrained "minimize rate s.t. lossless prediction" form is exactly
Rate(0); the trained objectives (VIC/BINCE, §4) are the Lagrangian rate + β·distortion.

### Claim 1(b): "all G-invariant tasks reduce to measurable functions of the invariant content / maximal invariant" (imported as R7(a)) — **VERIFIED-WITH-AMENDMENT**

Two distinct statements in App. B.1, and the amendment is which one R7(a) may lean on:

**Deterministic invariant functions — exact factorization (Lemma 5):**

> *"Let M be any maximal invariant w.r.t. (X,∼). Then a measurable function f: X → S is
> invariant with respect to (X,∼) if and only if there exists a measurable function h: M → S
> such that f(x) = (h∘M)(x) for all x ∈ X, in which case f is measurable with respect to the
> σ-algebra generated by M."*

**Stochastic invariant tasks — factorization of the conditional law, not of Y (Lemma 6):**

> *"Let X and Y be two random variables, and M: X → M be a maximal invariant w.r.t. (X,∼) as in
> Definition 2. Then Y is conditionally invariant w.r.t. (X,∼) as in Definition 3 if and only
> if Y ⫫ X | M(X)."*
>
> Lead-in: *"Finally, we establish a key conditional independence relationship, which shows
> that for invariant tasks, Y − M(X) − X forms a Markov Chain. This is a generalization of an
> probabilistic group theoretical results (Theorem 4.4 in Eaton [19], Theorem 7 in Bloem-Reddy
> and Teh [58]), to any equivalences (rather than only group orbits) and without making the
> assumption of (marginal) invariance of P(X) to ∼."*

Consequence for prediction (Corollary 9): *"For any Y ∈ T∼, R[Y|M(X)] = R[Y|X]"* (any loss).

**Conditions** (App. A.2–A.3): standard Borel spaces (ensuring regular conditional
distributions — Assumption 2 / probability kernels); measurable projection π∼ (Assumption 3,
*"holds for essentially all practical purposes"*), which guarantees a maximal invariant exists
(Lemma 7); finite risks (Assumption 1). Maximal invariant (Definition 2): measurable M with
x ∼ x′ ⟺ M(x) = M(x′); unique up to bijection (Lemma 4). For the log-loss/rate results
additionally: countably many equivalence classes (Assumption 4) and existence of densities
(Assumption 5, convenience).

**Amendment:** as literally worded ("tasks reduce to measurable functions of U"), the statement
is exactly true for deterministic invariant functions/labelings (Lemma 5); for stochastic tasks
Y it is the **conditional law / predictive content** that factors through M(X) (Lemma 6:
Y ⫫ X | M(X); the random variable Y is not itself a function of M(X)). Compact citable form of
the deterministic version also appears in Dubois '22 §3.1, crediting '21: *"any ∼-invariant
function g can be written as a composition between some function c_g and a maximal invariant
M [12], i.e., g = c_g ∘ M"*, and for tasks: *"Labels can thus be written as some function c_t
of M, i.e., argmax_y p_t(y|X) = c_t(M(X))."* R7(a) should say "measurable functions of the
maximal invariant (deterministic labelings; conditional laws factor through it in general)" and
may keep "G-invariant" only as the special case the paper explicitly generalizes.

### Claim 1(c): one readout tier only; no linear-vs-nonlinear distinction in the guarantee — **VERIFIED**

The guarantee is stated in Bayes risk with an **unconstrained** infimum. Main text (§3.1):
*"Let R[Y|X] denote the Bayes (best possible) risk when predicting Y from X. … R[Y|X] :=
inf_q E_{p(X,Y)}[−log q(Y|X)]"* — no function class. General-loss version (App. A.1):
*"R_L[Y|X] := inf_{h: X→A} E_{P(X,Y)}[L(Y, h(X))]"* — h ranges over all (measurable)
predictors. The paper says so itself when discussing experiments (§5):

> *"Table 2 provides the test performance for MLPs, while our theory discusses Bayes risk,
> which is independent of specific predictors and generalization."*

"Linear" appears only in practice remarks, e.g. BINCE *"giving (for suitable f_ψ)
representations that are approximately linearly separable [29,30,31]"* and App. empirical
probing (*"Table 10 shows that the advantage of using an MLP compared to a linear model is
small"*). No probe-family parameter exists anywhere in Prop. 1 / Theorem 2. Note also Lemma 8
(App. B.1) is a **data-processing inequality for Bayes risk** (citing Xu & Raginsky) — the
guarantee lives exactly in the unconstrained regime whose DPI V-information deliberately breaks
(cross-link to §3 below).

## 2 · Paper 2 — Dubois et al. '22, arXiv 2209.06235

### Claim 2(a): adds linear predictability of invariant tasks + dimension requirements — **VERIFIED**

Abstract: *"Specifically, we prove necessary and sufficient conditions such that for any task
invariant to given data augmentations, desired probes (e.g., linear or MLP) trained on that
representation attain perfect accuracy."*

Core characterization (§3.1, **Theorem 1**), verbatim (math transcribed):

> *"An encoder φ\* is sample optimal for ∼-invariant tasks T and linear F if and only if*
> - *F-predictability of M: there exists a max. invariant M and an f ∈ F s.t. M(X) = f(φ\*(X));*
> - *Invariance: φ\* is ∼-invariant, i.e., for any x, x⁺ ∈ X we have x ∼ x⁺ ⟹ φ\*(x) = φ\*(x⁺);*
> - *Dimensionality: the effective dimensionality of the representations is at least one less
>   than the number of equivalence classes, i.e., dim(span({φ\*(x) | x ∈ X})) ≥ |X/∼| − 1."*

Dimension statements: Fig. 2 caption — *"Linear classifiability of M(X) ensures population
optimality iff the dimensionality is at least |X/∼| − 1."* §7 — *"Theorem 1 shows that linear
ISSL requires a dimensionality of d = |X/∼| − 1 to ensure predictability of all invariant
tasks."* Non-linear probes (§5): *"the dimensionality requirement decreases with the complexity
of F⁺, e.g., for universal F⁺ it is d ≥ 1. More generally, the necessary dimension and the
sufficient dimension for optimality do not coincide and respectively depend on the predictors'
VC dimension [13] and memory capacity [39]."*

Scope conditions: finite input space X; deterministic invariant labelings (Definition 1;
stochastic labelings deferred to appendices); 0-1 risk / "perfect accuracy" (Defs. 2–3:
population optimality inf_{f∈F} R_t(φ,f) = 0, sample optimality adds minimizing worst-case
ERM risk W_n over all n). Note the guarantee routes linear predictability of *all* invariant
tasks through linear predictability *of the maximal invariant* plus the dimension condition.

### Claim 2(c): theory stated at the loss layer; projection heads / two-space distinctions absent — **REFUTED as stated (heads are central and theorized); what is absent is the two-space *audit*)**

Projection heads are not absent — they are a headline contribution:

- Abstract: *"our framework prescribes simple but significant improvements to previous methods
  such as using asymmetric projection heads."*
- §4.1 (CISSL): *"we can replace g by g′∘φ where g′: ℝ^d → S is called a projection head. …
  This is very similar to SimCLR's objective … The difference is that, by projecting the
  current representation, SimCLR learns encoders that are not even population optimal for
  linear F. … In ISSL, representations φ(x) — rather than their projections g′(φ(x)) — should
  thus be used in the inner product … CISSL thus derives, from first principles, an asymmetric
  use of projection heads."*
- §5 (non-linear probes): *"we should use a projection head that ensures the predictability of
  the maximal invariant with using the desired probes F⁺."*
- §6: *"Secs. 4 and 5 theoretically show how to choose projection heads, namely, one should be
  as large as possible while the other should have the architecture of downstream probes. To
  our knowledge, we are the first to relate the architecture of the probing family and the
  projection head."*
- App. D: *"To our knowledge, we are the first to theoretically prove and derive the need for
  projection heads. In particular, we show that we should only project one of the two
  representations…"*; on DINO/SwAV: *"the main difference in the student is that they use a
  non-linear projection head before the softmax, which … does not ensure linear predictability
  of downstream tasks."*

Moreover the theory is stated at the **representation/probe layer**, not the loss layer:
Theorem 1's conditions are on φ(X) (what probes see), and the loss is engineered so its
minimizers satisfy them. What *is* genuinely absent — and is our project's axis — is the
**two-space audit**: no desideratum is ever measured at both φ(X) and the head output and
compared; no statistical/marginal claims at either space; head-layer geometry itself is never
characterized. Note the §4.1 sentence above is a theory-level h-vs-z statement (symmetric
projection ⇒ loss of representation-layer optimality) — an anchor our framework note should
import rather than deny. Residual accuracy in the old row: '22 fixes **one probe family per
guarantee** (linear in §3–4, F⁺ in §5); it never treats two tiers simultaneously nor defines a
cross-tier gap object like Δ = I_{V₂} − I_{V₁}.

## 3 · Paper 3 — Xu et al. '20, arXiv 2002.10689

### Claim 3(a): the V-information definition — **VERIFIED**

§2, Definition 1 (Predictive Family), math transcribed: with Ω = {f: X ∪ {∅} → P(Y)}, V ⊆ Ω is
a predictive family iff *"∀f ∈ V, ∀P ∈ range(f), ∃f′ ∈ V, s.t. ∀x ∈ X, f′[x] = P, f′[∅] = P"*
(Eq. 1, "optional ignorance"). *"A predictive family is a set of predictive models the agent is
allowed to use, e.g., due to computational or statistical constraints."*

§2, Definition 2 (Predictive conditional V-entropy): *"H_V(Y|X) = inf_{f∈V} E_{x,y∼X,Y}
[−log f[x](y)]; H_V(Y|∅) = inf_{f∈V} E_{y∼Y}[−log f[∅](y)]"*; H_V(Y) := H_V(Y|∅).

§2, **Definition 3 (Predictive V-information)**, verbatim:

> *"Let X, Y be two random variables taking values in X × Y, and V be a predictive family. The
> predictive V-information from X to Y is defined as*
> I_V(X→Y) = H_V(Y|∅) − H_V(Y|X).  (Eq. 3)"

Recovers Shannon: *"if the V is the largest possible predictive family that includes all
possible models, i.e. V = Ω, then Definition 2 reduces to Shannon entropy"* (§2, with Prop. 1
covering other special cases, e.g. trace of covariance). DESIDERATA's gloss "I_V(Z→t) =
information usable by function class V" matches modulo notation.

### Claim 3(b): "data processing inequality fails by design — computation can CREATE usable information" — **VERIFIED**

Abstract: *"Unlike Shannon's mutual information and in violation of the data processing
inequality, V-information can be created through computation."* §1: *"A consequence of this new
formulation is that computation can 'create usable information' (e.g., by decrypting the
intercepted messages), invalidating the famous data processing inequality."*

§3.2 ("On the production of information through preprocessing") argues the violation is
intended, not incidental — supporting the "by design" gloss:

> *"The Data Processing Inequality guarantees that computing on data cannot increase its mutual
> information with other random variables. … But is this property desirable? In analyzing
> optimal communication, yes … However, we argue that in machine learning settings this
> property is less appropriate."*

The example, verbatim (RSA): *"decryption increases a human's ability to predict the label:
processing increases the 'usable information'. More formally, denoting t as the decryption
algorithm and V as a class of natural language processing functions, we have that:
I_V(t(X)→Y) > I_V(X→Y) ≈ 0."* And for representation learning: *"the fundamental principle of
representation learning is precisely the ability to learn predictive features — functions of
the raw inputs that enable predictions with higher accuracy. Because of this key difference
between V-information and Shannon information, machine learning practices such as
representation learning can be justified in the information theoretic context."*

Balancing note: Prop. 2 (§3) shows which Shannon properties are *kept*: monotonicity in V,
non-negativity I_V(X→Y) ≥ 0, and independence ⇒ zero. §3.3 adds asymmetry
(I_V(X→h(X)) ≫ I_V(h(X)→X) for one-way h).

### Claim 3(c): a measurement language, not a learning objective — **VERIFIED-WITH-AMENDMENT**

The paper's contributions are definitional (§2), structural (§3), and **estimation-theoretic**:
§4 gives PAC bounds for empirical V-information (Definition 4) — motivated by measurement:
*"V-information can be provably estimated"* (conclusion). Applications are analyses, not new
training losses: structure learning (Chow-Liu trees with I_V edge weights, with finite-sample
guarantees), frame-order recovery, and gene-network recovery. No new representation-learning
objective is proposed anywhere.

**Amendment (two caveats):** (i) §6.4 + App. D.2 *reinterpret existing* adversarial
fair-representation methods as V-information minimization — *"we show in Appendix D.2 that
these works actually use V-information minimization as part of their objective, where V depends
on the functional form of the discriminator"* — and App. D.2 writes the objective min_φ
I_V(Z→U) explicitly to run the cross-family attack experiment (features trained under V_i
leak under V_j: *"previous methods work well at preventing information 'leak' against the class
of adversary they've been trained on, but fail when we consider different ones"*). So I_V does
appear inside a (pre-existing) training objective once, as an analysis instrument. (ii) The
discussion defers objective-side use to future work: *"The production of usable information
(representation learning), acquisition … and exploitation … could potentially be framed in a
similar V-information-theoretic manner."* For our purposes ("measured, never trained", trd_pi
D4) the claim stands with these caveats.
